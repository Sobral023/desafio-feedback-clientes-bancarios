Projeto de Prompt Engineering desenvolvido no Bootcamp Bradesco GenAI da DIO.

# Desafio Criativo — Extraindo Insights do Feedback de Cliente Bancário

## Sobre o projeto

Este projeto tem como objetivo utilizar Inteligência Artificial Generativa para analisar feedbacks de clientes bancários, identificando padrões, sentimentos e oportunidades de melhoria na experiência do cliente.

## Objetivo

Criar um prompt capaz de orientar uma IA Generativa na análise de opiniões de clientes, transformando dados de feedback em informações úteis para tomada de decisão.

## Arquivo do projeto

- `prompt-final.md` — contém o prompt desenvolvido para análise dos feedbacks dos clientes.

## Tecnologias utilizadas

- Inteligência Artificial Generativa
- Engenharia de Prompt
- Markdown
